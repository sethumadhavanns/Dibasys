# Dibasys
Dibasys App

Dibasys is a Flutter-based mobile application developed with clean architecture and modern development practices for maintainability, responsiveness, and smooth user experience.

Key Features & Implementation Details

State Management: Implemented using Provider, allowing reactive UI updates and clean separation of business logic from UI.

Responsive Design: Used Flutter ScreenUtil to ensure UI scales correctly across different screen sizes and devices.

Animations: Added custom animations for screen transitions:

Login → Home screen slides up smoothly.

Check-in screen transitions with slide effect for better UX.

Architecture: Followed MVC (Model-View-Controller) pattern to separate concerns and maintain scalable code structure.

Global Widgets & Files: Created reusable widgets and global configuration files for:

Colors, text styles, and constants.

Buttons and common UI components.

Functions and utilities accessible across the app.

User-Friendly UI: Designed screens with intuitive layouts and smooth interactions.

Technologies & Packages Used

- Flutter & Dart

- Provider (State Management)

- Flutter ScreenUtil (Responsive UI)

-  Gap (Spacing)
  
- Custom Widgets for reusable components

  Development Environment

-  Flutter Version: 3.35.4 (Stable Channel)

-  Dart Version: 3.9.2
